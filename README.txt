SHRIKANT PATIL — PORTFOLIO WEBSITE

Files:
- index.html : page content
- style.css : responsive design and styles
- script.js : mobile navigation and contact form behavior

HOW TO RUN:
1. Extract this ZIP.
2. Open the folder.
3. Double-click index.html, or open it with VS Code and use Live Server.

CUSTOMIZE:
- Edit your intro, skills and projects in index.html.
- Replace the LinkedIn URL with your real profile URL.
- The contact form opens the visitor's email application (mailto); it does not send email automatically or require a backend.
- Add your resume file and link it from the hero section if you want a resume download.
